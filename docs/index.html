Sources

  • Chat & coding scores and list pricing: arena.ai leaderboards (parsed live, no API key)
  • Foundry pricing (GPT models): Azure Retail Prices API (public, no auth)
  • OpenRouter pricing: openrouter.ai model list API, matched by normalized name (best-effort)

Methodology notes

"Direct" pricing is Arena's own listed rate for each model, not a separately scraped vendor pricing page — this script doesn't parse prose pricing pages, only structured/API sources.

Claude models on Microsoft Foundry bill through "Claude Consumption Units" — an invoicing format, not a separate price. Microsoft's own docs confirm it converts tokens using Anthropic's own published rate with no markup by default, so Foundry is shown equal to Direct for Anthropic models here.

Known limitations

OpenRouter matching is name-based best-effort — a model can show "n/a" there even if OpenRouter does list it, if the naming doesn't line up. This is a deliberate fail-safe (never guess) rather than a bug to chase.

If Arena changes its page markup, the parser may return too few rows and the scheduled run will exit without publishing a broken page — check the workflow run logs if the site stops updating.
